# Sahil Verma — Investment Portfolio

A lightweight personal portfolio website showcasing:

- Investment research
- Financial modelling
- Portfolio construction
- Credit-risk analytics
- Python / SQL
- AI-assisted financial research

## Run locally

No build system or dependencies are required.

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from branch**.
4. Choose `main` and `/ (root)`.
5. Save.

## Important

Replace placeholder GitHub, LinkedIn and email links in `index.html` before publishing.
